# 豆包使用与 skill 安装说明

核对日期：2026-10-31。下面区分“把指令交给聊天助手”和“客户端安装技能”，避免照着帖子找不到按钮。

## 普通豆包：复制指令路线

1. 打开 GitHub 仓库中的 `prompts/doubao-copy.md`，查看文件内容。
2. 复制正文，打开豆包新对话，把主题、人群和题数改成自己的需求后发送。
3. 先看方案和计分表；确认后让它生成完整 HTML。
4. 如只能得到代码，在记事本等纯文本编辑器保存为 `index.html`，编码 UTF-8，文件类型“所有文件”。避免文件名变成 `index.html.txt`。
5. 双击浏览器试用，从开始到下载报告完整测试。不要把 AI 自述的“检查完成”当作实际运行证据。

以上不需要寻找“导入 GitHub Skill”按钮，也不声称已安装持久技能。界面、附件读取和代码输出能力可能随版本变化，文字复制可在能正常发送长文本的对话中使用。

## 豆包工作：已上架技能路线

官方文档描述用户安装商店已上架技能；GitHub 上传和平台上架是不同步骤。本包尚未完成平台上架，不能给出可用商店链接或宣称能够直接安装。如果以后上架成功，再补充实际详情链接及真实界面操作。

## 其他 Agent Skills 客户端

按相应客户端的官方文档选择项目级或个人技能目录，复制整个 `quiz-website-builder` 目录。保留 `scripts/`、`assets/`、`references/` 的相对关系。重载后，用自然语言或客户端的技能选择器明确调用；具体重载方式以该客户端为准。

如果客户端只能读取指令、不能执行脚本，使用聊天提示词路线。不把“有一份 SKILL.md”说成任何 AI 都能执行全部步骤。
