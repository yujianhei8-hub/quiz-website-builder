# 电脑端制作与使用说明

本教程在电脑端进行资料评审、文件生成、修改、浏览器测试和发布；成品网页优先适配手机，同时兼容电脑。手机仅作为成品验收设备，不在教程中讲手机制作或安装技能。

## 豆包普通对话：复制提示词

在电脑端打开豆包新对话，复制 prompts/doubao-copy.md，填写主题后发送。先研究和评审方案，确认后生成原型，反馈修改，接受原型后审查交付。这是在当前对话中使用指令，不是安装永久技能。

不承诺具体客户端一定能联网、读取附件、运行脚本、生成下载文件或自动部署。没有文件输出时，索取完整HTML代码，在纯文本编辑器中以UTF-8、所有文件类型保存为 index.html，避免 .html.txt。小红书教学直接提供提示词，无需公开作者GitHub用户名或要求读者下载ZIP。

## 支持 Agent Skills 的电脑端客户端

按客户端官方安装说明，将完整 quiz-website-builder 文件夹添加到相应技能目录，保留 SKILL.md 与 scripts、assets、references 等相对关系。安装方法以目标客户端实际支持为准，不把GitHub地址说成通用安装命令。安装后明确调用本技能制作网站。

## 测试与发布

在电脑浏览器从首页答到结果，返回改选并检查保存。优先检查360/390/430像素窄屏，再检查电脑布局；上线后用真实手机打开正式链接复查。桌面窄屏模拟不等于真机验证。

纯静态HTML可部署到静态托管平台，使用平台分配的网址；不必自行购买服务器或自定义域名。平台可用性、价格和限制应在选定时查证。需要账号、兑换码、次数控制或云端数据时，另行设计后端/数据库；前端口令不是可靠付费保护。生成HTML不等于已上线，区分文件入口与正式访问地址。
