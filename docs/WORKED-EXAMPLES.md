# 一个方向如何变成不同报告

## 输入：我想做逃避心理分析测试

助手先扩展概念、近义词和区别项，搜索情境、应对功能、影响、形成条件、反例及改变路径；实际保存检索记录、材料适用范围和观点。确定面向日常自我探索还是其他目标，再提出方案供用户确认。

报告可按“你的主要模式 → 多维画像 → 最容易触发的场景 → 反应循环 → 短期保护与长期代价 → 可能的形成条件 → 当下影响 → 条件化的未来情景 → 改善方向”组织。人物或动物是表达层，可以不用，不改变实际计分。

从报告倒推题目：需要分析反应循环，就必须问触发、想法、行为和后果；需要讨论过去线索，就在答题中收集可选择不披露的经历信息。没有过去自述或合适材料时，改为解释常见触发条件，不编造用户经历，也不交付“报告未完成”。

## 输入：我像哪个历史人物

助手先明确比较范围、维度、人物档案和史料标准，再研究具体人物。不以“著名”代替维度完整，不用合成档案冒充真实人物研究。

报告可按“最相似人物与百分比 → 多维对照 → 相似点与不同点 → 其他相邻人物 → 时代环境差异 → 可借鉴之处”组织。不照搬逃避心理的个人成因报告。

相似度 = 100 × [1 − Σ(权重 × 用户与人物的归一化维度距离) / Σ可比较权重]。缺失维度单独计覆盖率，覆盖不足不参与排名；同分并列。这个百分比不是‘你有多少概率就是这个人’。

## 模块怎样真正参与链路

每个模块都有回答需求、资料需求、图形候选、解释边界和替代模块。它先约束研究与出题，再约束计分和报告渲染，最后成为验收项目。8类主目的只是起点，可按需求组合新模块；36种图形是选型库，不要求一份报告塞满36种图。

方案确认前输出蓝图；确认后才做可答题原型；用户反馈进入修改；用户接受原型后再审查并交付。规则检查器辅助记录阶段，不能替代真实用户的确认。
