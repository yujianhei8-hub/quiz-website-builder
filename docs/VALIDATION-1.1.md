# v1.1.0 扩展验证

日期：2026-11-01。

新增：主题检索与资料库工作流、来源到产品的ID映射、36种图形适用规则与SVG演示、8套颜色角色、10种问答结构、6种结果布局、8种情境、豆包复制指令更新。

## 已验证

- 资料库ID与引用完整，示例9题和3结果均有映射。
- 缺失来源、UI来源冒充主题依据、只读元数据作为结论依据、原创规则假冒验证计分，这4种负例均被校验拒绝。
- 8套配色的主字/背景、主字/卡片、次字/背景、次字/卡片、按钮字/按钮底色，均达到4.5:1。只涵盖这几类颜色组合，不是完整WCAG认证。
- 原有19,683条回答路径与9项逻辑回归仍通过；示例报告新增按真实计算值绘制的方向图。
- 图集36种SVG均能实际渲染，筛选数据类型、搜索雷达、8套主题切换、展开启动方案均通过Chrome无头浏览器检查。合成树图面积与桑基流量按演示数值绘制。
- 图集390px宽度无横向溢出，桌面与窄屏截图保存在 `docs/browser/`。
- 图集独立HTML入口为 `demo/design-atlas.html`；示例测试入口为 `demo/index.html`。

## 边界

- 36种是图形目录与合成演示，不是36种可直接套任意数据的生产组件。测试起步模板内置条形、点图和棒棒糖；其他形式应按具体数据实施。
- 资料库提供结构和流程，不声称已替每种主题完成研究。示例周末规则未验证测量效度。
- 自动化可检查链接关系和显式标签，不能读懂论文替人做完整的证据评估。
- 配色检验不能覆盖所有图内标签、系统emoji、屏幕阅读器和设备差异；真实手机和辅助技术未全面验证。
- 未将本包上传GitHub、未在豆包客户端实测或上架其技能商店；公开链接留待作者发布后填入。
