# 结果页图形：36 种可选形式，而不是每份报告放 36 张

机器可读目录在 `assets/design-library.json`。交互预览见 `demo/design-atlas.html`。这些是设计图形库，不是实证支持库。图集的演示数据全部为合成/示意。

## 先选读者要做的决定

- 看谁更高：条形、点图、棒棒糖。看差距：子弹图、哑铃、发散条。
- 看变化：折线、斜率、时间线；必须真的有时间或前后观测。
- 看整体构成：堆叠、环形、华夫；类别要互斥，且能组成明确整体。
- 看分布：直方、箱线、密度、ECDF、条带；要有实际观测样本，不把一个人的几个答案假装成常模。
- 看关系：散点、气泡、网络、桑基；关系和流量要有定义，不凭性格故事画因果。
- 看多维与行动：热力/比较矩阵、雷达、平行坐标、象限、甘特。原始变量和单位仍需清楚。

## 图形目录（ID 与 JSON 一致）

| ID | 形式 | 可回答的问题 / 必要条件 |
|---|---|---|
| bar | 水平条形 | 比较方向大小；共同起点，明确上界 |
| dot | 点图 | 多个方向的位置；共同刻度 |
| lollipop | 棒棒糖图 | 排名和距离；长度以零为基线 |
| bullet | 子弹图 | 当前值和目标差距；目标由用户/规则定义 |
| diverging | 发散条形 | 相对中性点的两端；真实中点，不能硬设两极人格 |
| dumbbell | 哑铃图 | 两条件/两时点差值；同量纲配对 |
| slope | 斜率图 | 前后相对变化；两个真实时间点 |
| line | 折线图 | 连续序列趋势；时间间隔和测量相容 |
| sparkline | 迷你趋势线 | 小区域内重复测量走势；保留时间/范围 |
| area | 面积图 | 非负总量随时间；不暗示无根据的累计 |
| range-band | 区间带 | 估计或观测范围；给出范围的定义和来源 |
| box | 箱线图 | 样本位置和分散；统计口径清楚 |
| histogram | 直方图 | 样本频数分布；披露分箱与样本量 |
| density | 密度图 | 样本分布形状；平滑是假设，非个人置信度 |
| ecdf | 累积分布 | 样本中不高于某值的比例；有合适样本 |
| strip | 条带图 | 一组真实观测；点可对应到数据 |
| scatter | 散点图 | 两变量的共变；相关不代表因果 |
| bubble | 气泡图 | 两轴加第三数量；面积而非半径编码数量 |
| heatmap | 热力图 | 行列交叉的数值强弱；共同色标 |
| matrix | 比较矩阵 | 方案条件是否满足；明确分类标签 |
| radar | 雷达/蜘蛛图 | 少量相同范围维度概览；轴序固定，不比较多边形面积 |
| parallel | 平行坐标 | 多方案的多维轮廓；说明逐轴归一化，避免线太多 |
| stacked | 堆叠条形 | 数量和组成；各部分可相加 |
| stacked-100 | 百分比堆叠 | 互斥整体的组成；不能放独立匹配分 |
| donut | 环形图 | 少数互斥部分的构成；总量有意义 |
| waffle | 华夫图 | 有分母的离散比例；格子数就是分母表达 |
| treemap | 矩形树图 | 有层级的组成；面积可相加，别用来精确排名 |
| sunburst | 旭日图 | 多级分类及占比；祖先后代关系真实 |
| sankey | 桑基图 | 有数量的流转；结点守恒/外部流入有说明 |
| network | 关系网络 | 已定义的关联与路径；连线不证明因果 |
| timeline | 时间线 | 事件及先后；计划和真实事件分开标记 |
| gantt | 甘特图 | 启动计划任务的起止与重叠；估计工期不是事实预测 |
| waterfall | 瀑布图 | 起点加减贡献到终点；贡献必须可加和 |
| small-multiples | 小多图 | 多方案同一视角对照；同尺度，不能各自放大 |
| quadrant | 四象限 | 两个已定义连续维度的取舍；分界有理由，不伪造人格分组 |
| pictogram | 单位图标图 | 真实数量/比例的直观表达；每图标单位固定 |

## 每张图都绑定一份数据合同

至少包含 `metricId, label, origin, unit, bounds/denominator, population, timestamp, missing, transformation, chartId, explanation, accessibleSummary`。分清真实个人回答、原创规则指数、外部事实、群体常模、计划估计和示意数据。

没有同类基准就不显示“超过 90% 的人”；没有前测就不画成长趋势；没有误差估计就不画置信带。图形不能增加数据原本没有的信息。

无论图形多精致，结果页都应回答：这个值代表什么、为什么与用户有关、下一步如何选择。只统计勾选次数时，应该明确叫次数，不能换名字冒充深层性格。

## 视觉与可访问性

同一指标的方向颜色、尺度和标签在全文一致。数值图需要刻度或直接标签；颜色之外再给文字/形状。图下提供短结论和可展开的数据表。窄屏可切换为条形/列表，图集有 36 种选择不代表 36 种都适合移动报告。常规情况下选 2–4 张能支持判断的图。

技术类型参考：[Vega-Lite 官方示例](https://vega.github.io/vega-lite/examples/)。本目录的题目和报告适配规则为本项目设计建议，不是 Vega 官方的测评规范。
